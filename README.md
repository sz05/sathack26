# Lecture Doubt Solver

Students watch recorded lectures, get stuck on one line, and never find the answer again. This project lets a student pause a lecture, ask a doubt in their own words, and get an answer that points to the exact moment in the recording where the topic is explained.

> Hackathon prototype. Status: in progress.
